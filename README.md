# 🐾 Pet Adoption Platform (ระบบรับเลี้ยงสัตว์เลี้ยง)

แพลตฟอร์มค้นหา ลงประกาศ และรับเลี้ยงสัตว์เลี้ยงแบบครบวงจร (Full-Stack Monorepo Application) พร้อมระบบประเมินความพร้อม แชทพูดคุย การแจ้งเตือนอัตโนมัติ การส่งรูปอัปเดตความเป็นอยู่หลังรับเลี้ยง และการรีวิวผู้ใช้งาน

---

## 🛠 Tech Stack

- **Frontend:** Next.js 16 (App Router), TypeScript, Tailwind CSS, Lucide React
- **Backend:** Node.js, Express.js, Prisma ORM 7, PostgreSQL
- **Authentication:** JWT (JSON Web Tokens) with HTTP-only cookies / Bearer headers
- **Database:** PostgreSQL (Docker / Local)

---

## 🚀 Quick Start & Setup Guide (การติดตั้งและเริ่มต้นใช้งาน)

### 1. การตั้งค่า Environment Variables
ตรวจสอบไฟล์ `.env` ที่โฟลเดอร์หลัก หรือสร้างจากตัวอย่าง:
```bash
# backend/.env
PORT=5000
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/pet_adoption_db?schema=public"
JWT_SECRET="supersecretjwtkey"

# frontend/.env
NEXT_PUBLIC_API_URL="http://localhost:5000/api/v1"
```

### 2. รันด้วย Docker Compose (แนะนำ)
คำสั่งเดียวสำหรับรันทั้ง PostgreSQL, Express Backend, และ Next.js Frontend:
```bash
docker compose up -d --build
```
- 🌐 **Frontend:** [http://localhost:3000](http://localhost:3000)
- 🔌 **Backend API:** [http://localhost:5000/api/v1](http://localhost:5000/api/v1)

### 3. รันแบบ Local Development
**ขั้นตอนที่ 1: รัน Database (PostgreSQL)**
```bash
docker compose up -d postgres
```

**ขั้นตอนที่ 2: ติดตั้ง Dependencies และรัน Backend**
```bash
cd backend
npm install
npx prisma generate
npx prisma migrate dev --name init # หรือรัน seed
npm run mockData                   # นำเข้าข้อมูล Mock Data สำหรับทดสอบ
npm run dev                        # เริ่มรันที่ http://localhost:5000
```

**ขั้นตอนที่ 3: ติดตั้ง Dependencies และรัน Frontend**
เปิดอีกหนึ่ง Terminal:
```bash
cd frontend
npm install
npm run dev                        # เริ่มรันที่ http://localhost:3000
```

## 📖 คู่มือการใช้งาน (How to Use)

### 🐾 รูปแบบที่ 1: สำหรับผู้สนใจรับเลี้ยงสัตว์เลี้ยง (Adopter Journey)

#### 1. ค้นหาและดูข้อมูลสัตว์เลี้ยง (`/`)
- เข้าสู่หน้าแรก ระบบจะแสดงการ์ดสัตว์เลี้ยงทั้งหมดที่เปิดรับเลี้ยง
- ใช้งานแถบตัวกรอง (Filters):
  - **ชนิดสัตว์:** ทั้งหมด, สุนัข, แมว, อื่นๆ
  - **สายพันธุ์:** พิมพ์ชื่อสายพันธุ์ (เช่น บางแก้ว, วิเชียรมาศ)
  - **พื้นที่/ที่พักพิง:** พิมพ์ทำเลที่ตั้ง
  - **สถานะ:** available (เปิดรับเลี้ยง), pending (รอตัดสินใจ), adopted (ได้บ้านแล้ว)
- คลิกรูปหัวใจ **♡** บนการ์ด เพื่อบันทึกเข้าสู่ **Wishlist** ส่วนตัว

#### 2. ดูรายละเอียดและประวัติสุขภาพ (`/pets/[id]`)
- คลิกที่การ์ดสัตว์เลี้ยงเพื่อเปิดหน้ารายละเอียด
- ตรวจสอบประวัติสุขภาพ (โรคประจำตัว, การฉีดวัคซีน, การทำหมัน) และเงื่อนไขการรับเลี้ยง
- ดูข้อมูล **โปรไฟล์ผู้ลงประกาศ** (วันที่สมัคร, จำนวนประกาศ, คะแนนเฉลี่ย) และ **รีวิวจากผู้รับเลี้ยงคนอื่น**
- ปุ่มการทำงาน:
  - **♡ Wishlist:** บันทึก / ลบออกจากรายการโปรด
  - **แชทสอบถาม:** เปิดห้องสนทนาเพื่อพูดคุยกับเจ้าของสัตว์เลี้ยง
  - **สนใจรับเลี้ยง:** เปิดแบบฟอร์มประเมินความพร้อม

#### 3. ยื่นแบบประเมินความพร้อมรับเลี้ยง (`/pets/[id]/apply`)
- กรอกข้อมูลความพร้อม: ประเภทที่อยู่อาศัย, ช่วงรายได้, ประสบการณ์เลี้ยงสัตว์, จำนวนสมาชิกในบ้าน, และเหตุผลที่ต้องการรับเลี้ยง
- กดยอมรับเงื่อนไข แล้วคลิก **"ส่งความสนใจ"**
- ระบบจะบันทึกใบสมัคร และเปิดห้องแชทพร้อมส่งข้อความทักทายไปยังผู้ลงประกาศโดยอัตโนมัติ

#### 4. รับการแจ้งเตือนผลการคัดเลือก (`/notifications`)
- เมื่อเจ้าของประกาศคัดเลือกคุณ:
  - จะได้รับข้อความแชทอัตโนมัติแจ้งข่าวดีทันที
  - ในหน้า **แจ้งเตือน** (`/notifications`) จะแสดงการ์ดแสดงความยินดี พร้อมข้อมูลสัตว์เลี้ยงและผู้ลงประกาศ
  - สามารถกดปุ่ม **"แชทกับเจ้าของ"** เพื่อนัดหมายวัน เวลา และสถานที่รับมอบน้อง

#### 5. ติดตามและส่งรูปอัปเดตความเป็นอยู่ (`/pets` & `/pets/[id]/updates`)
- หลังรับน้องมาเลี้ยงเรียบร้อย สัตว์เลี้ยงจะปรากฏในตาราง **"สัตว์ที่รับเลี้ยง"** ที่หน้า `/pets`
- คลิก **"ดูอัพเดต"** หรือ **"ส่งรูปอัปเดต"** เพื่อส่งรูปภาพความเป็นอยู่ (3–5 รูป) ตามรอบ (1 เดือน, 3 เดือน, 6 เดือน, 1 ปี)
- คลิก **"รีวิวเจ้าของ"** เพื่อให้คะแนนและเขียนรีวิวผู้ลงประกาศเดิม

### 🏠 รูปแบบที่ 2: สำหรับผู้ลงประกาศหาบ้านให้สัตว์เลี้ยง (Pet Owner Journey)

#### 1. สร้างประกาศหาบ้านใหม่ (`/pets/create`)
- คลิกปุ่ม **"+ ลงประกาศหาบ้าน"** ที่มุมขวาล่างของหน้าแรก หรือเลือกจากเมนูโปรไฟล์
- อัปโหลดรูปภาพสัตว์เลี้ยง (สูงสุด 5 รูป)
- กรอกชื่อ, ประเภทสัตว์, เพศ, อายุ, สายพันธุ์, ที่พักพิง/ทำเล
- บันทึกประวัติสุขภาพ (โรคประจำตัว, วัคซีน, การทำหมัน) และแนบเอกสารรับรอง
- ระบุเงื่อนไขการรับเลี้ยง และคลิก **"สร้างประกาศ"**

#### 2. จัดการประกาศของฉัน (`/pets`)
- ตรวจสอบรายการสัตว์เลี้ยงในตาราง **"ประกาศของฉัน"**
- คอลัมน์ **"ผู้สนใจ"** จะแสดงจำนวนผู้ที่ส่งแบบประเมินความพร้อมเข้ามา
- คลิกที่จำนวนผู้สนใจ เพื่อเปิด Modal **"รายชื่อผู้สนใจรับเลี้ยง"**

#### 3. คัดเลือกผู้รับเลี้ยง และแจ้งเตือนอัตโนมัติ (Selecting & Notifying Recipient)
สามารถเลือกผู้รับเลี้ยงได้ 2 วิธี:
- **วิธีที่ 1 (จากหน้าประกาศของฉัน):**
  1. ในหน้า `/pets` คลิกดูรายชื่อผู้สนใจของสัตว์เลี้ยง
  2. ตรวจสอบข้อมูลความพร้อมของผู้สมัคร และคลิก **"แชทสอบถาม"** หากต้องการพูดคุยเพิ่มเติม
  3. คลิกปุ่ม **"เลือกผู้รับเลี้ยงนี้ (เป็น pending)"**
  4. ระบบจะปรับสถานะสัตว์เลี้ยงเป็น `pending` และ**ส่งข้อความแจ้งเตือนผู้รับเลี้ยงทันที**
- **วิธีที่ 2 (จากหน้าการแจ้งเตือน):**
  1. ไปที่หน้า `/notifications` คลิกเลือกใบสมัครที่ส่งเข้ามา
  2. ตรวจสอบข้อมูลฟอร์มประเมินและรีวิวของผู้สนใจ
  3. คลิก **"ตกลงให้รับเลี้ยง (→ pending)"**

#### 4. ยืนยันการส่งมอบเสร็จสมบูรณ์ (`adopted`)
- เมื่อนัดรับมอบสัตว์เลี้ยงเรียบร้อยแล้ว ให้คลิกปุ่ม **"ยืนยัน: adopted"**
- ปรากฏกล่องยืนยันพร้อมแสดงชื่อผู้รับเลี้ยงที่ได้รับการคัดเลือก
- เมื่อคลิกยืนยัน:
  - สัตว์เลี้ยงจะเปลี่ยนสถานะเป็น `adopted` (ซ่อนจากการค้นหาทั่วไป)
  - ระบบส่งข้อความแจ้งเตือนผู้รับเลี้ยงว่ากระบวนการรับเลี้ยงเสร็จสมบูรณ์ พร้อมเปิดสิทธิ์ให้เริ่มส่งรูปอัปเดต
- ปุ่ม **"รีวิว"** บนแถวประกาศจะเชื่อมต่อกับผู้รับเลี้ยงคนดังกล่าว ให้เจ้าของเดิมสามารถเขียนรีวิวผู้รับเลี้ยงได้ทันที

### 💬 ฟีเจอร์ศูนย์ข้อความแชท (`/chat`)

- **Contextual Pet Header:** แต่ละห้องสนทนาจะเชื่อมโยงกับสัตว์เลี้ยงที่เกี่ยวข้อง แสดงชื่อสัตว์ รูปภาพ และสถานะ
- **Quick Action Buttons:** มีปุ่มลัดด้านบนห้องแชทสำหรับ:
  - **ดูประกาศ:** ลิงก์ตรงไปยังหน้ารายละเอียดสัตว์เลี้ยง (`/pets/[id]`)
  - **ดูโปรไฟล์:** ดูข้อมูลแบบประเมินความพร้อมของผู้สมัคร (`/notifications`)
  - **ดูอัปเดต:** ตรวจสอบรูปภาพอัปเดตความเป็นอยู่หลังรับเลี้ยง (`/pets/[id]/updates`)
  - **รีวิว:** เขียนรีวิวคู่สนทนา (`/reviews`)
- **การแยกสิทธิ์ความเป็นส่วนตัว:** ผู้ใช้งานจะสามารถอ่านและส่งข้อความได้เฉพาะในห้องที่ตนเองเป็นคู่สนทนาเท่านั้น

---

### ⭐ ระบบรีวิว (`/reviews`)

- ให้คะแนนระดับ 1 ถึง 5 ดาว พร้อมเขียนความคิดเห็นบรรยายประสบการณ์
- สามารถรีวิวได้ทั้งสองฝั่ง:
  - ผู้ลงประกาศรีวิวผู้รับเลี้ยง (Adopter Review)
  - ผู้รับเลี้ยงรีวิวผู้ลงประกาศเดิม (Owner Review)
- คะแนนเฉลี่ยและรายการรีวิวจริงจะสะท้อนบนการ์ดโปรไฟล์ในหน้ารายละเอียดสัตว์เลี้ยงทันที

## 🧪 การทดสอบและตรวจสอบคุณภาพโค้ด (Testing)

### 1. ทดสอบ Backend API (76 Test Cases)
ทดสอบทุก Endpoints ครอบคลุม Auth, Pets, Applications, Wishlists, Updates, Chat, และ Reviews:
```bash
cd backend
npm run test:api
```
หรือทดสอบเฉพาะหมวดหมู่:
```bash
npm run test:api -- --suite pets
npm run test:api -- --suite applications
npm run test:api -- --suite messaging
npm run test:api -- --suite reviews
```

### 2. ทดสอบ Frontend Build
ตรวจสอบการคอมไพล์ TypeScript และ Next.js App Router:
```bash
cd frontend
npm run build
```
